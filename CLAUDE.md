# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a documentation/knowledge repository covering AI, Model Context Protocol (MCP), and Azure cloud integrations. It contains notes and reference material — no executable code, build system, or tests.

## Structure

- `claude-code/` — Claude Code mastery: CLI, commands, skills, hooks, config, prompting, memory
- `mcp/` — Model Context Protocol (general, catalog, building custom servers, Context7)
- `azure/apim/` — Azure API Management: concepts, Entra auth flow for MCP, policies
- `azure/foundry/` — Azure AI Foundry, Azure OpenAI deployments, how they connect
- `ai/` — AI fundamentals, Ollama local model guide
- `ai.md` — AI concepts: pattern recognition, ML, generative AI, RLHF

## Contributing

All content is Markdown. Add new topics as `.md` files in the appropriate directory, or create a new subdirectory for a new topic area.
